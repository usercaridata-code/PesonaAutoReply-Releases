Operasional bot

Wake lock

Jalankan «termux-wake-lock» di Termux untuk membantu saat layar mati.

TMUX

Gunakan «tmux attach -t botpkg» untuk kembali ke sesi bot yang sudah berjalan.

Kode 408

Periksa koneksi internet dan log reconnect Baileys.

Kode 440

Periksa apakah ada dua proses bot yang menggunakan sesi WhatsApp yang sama.

Kontrol start/stop, ganti nomor, dan perbaikan error otomatis belum diaktifkan karena bisa memutus koneksi bot aktif.

Arsip File melalui Telegram

Pilih file dari penyimpanan Android, lalu kirim secara manual ke «Pesan Tersimpan / Saved Messages» di Telegram. File tidak disimpan di Google Drive oleh aplikasi ini.

Aplikasi ini belum memiliki arsip terenkripsi otomatis atau sinkronisasi Telegram Bot API. Pastikan Anda memilih tujuan yang benar sebelum mengirim file sensitif.
